# AGENTS.md

## What is this

**Anonimus** — privacy-preserving Proof-of-Humanity + Uniqueness as a Service on Midnight Network. Compact contract (`poh_core.compact`) implements credential registry + campaign-scoped nullifier uniqueness via ZK proofs.

**Read `handoff.md` first** on any new session. It is the operating document (always current) and contains tooling rules, architecture decisions, research findings, and blockers.

## Commands

```bash
# Compile Compact contract (runs in WSL — compiler is Unix-only)
# From WSL shell:
compact compile contracts/poh_core.compact contracts/managed/poh_core

# TypeScript typecheck
yarn typecheck

# Run all tests (no test files exist yet — vitest configured but empty)
yarn test

# Run tests with local devnet
yarn test:local

# E2E against local devnet (requires devnet running + compiled contract)
yarn e2e
```

**No lint or formatter configured.** Only typecheck exists for static analysis.

## Architecture

```
contracts/
  poh_core.compact          ← Main contract (Compact language)
  smoke_test.compact        ← Toolchain smoke test (NOT product code)
  witnesses.ts              ← Witness implementations + test verifier
  index.ts                  ← Contract export + CompiledContract setup
  managed/poh_core/         ← GENERATED by compactc (don't edit)
    contract/index.js       ← TS bindings + pureCircuits
    compiler/               ← contract-info.json, manifest

  config.ts                 ← Network config (local devnet endpoints)
  wallet.ts                 ← MidnightWalletProvider (FluentWalletBuilder)
  providers.ts              ← Provider wiring (proof, indexer, private state)
  verifier.ts               ← Test verifier + attestation issuance
  e2e-local.ts              ← E2E script (deploy + query on local devnet)

scripts/                    ← WSL repair, Kapa auth, toolchain setup
devnet.yml                  ← Docker Compose for local devnet (3 services)
```

## Critical constraints

- **Compact compiler is Unix-only.** All `compact compile` commands must run inside WSL2 (Ubuntu-24.04). Compiler binary: `~/.compact/bin/compactc` (v0.34.0). Never try to compile Compact on Windows directly.
- **Compile syntax is positional**: `compact compile <source> <target-dir>` — no `-o` flag.
- **Never guess Midnight APIs.** Check `.tmp/midnight-expert/` (reference docs) or `.tmp/midnight-docs/` (full official docs clone) first. Kapa MCP (`https://midnight.mcp.kapa.ai`) is the priority research source but login is currently blocked server-side.
- **No mocks** for: PoH, biometric verification, Midnight proofs, contract behavior, nullifiers, wallet verification, or cryptographic signatures.
- **Pragma**: all Compact files must use `pragma language_version >= 0.22;`
- **Generated code**: `contracts/managed/` is produced by `compactc`. Never edit files there directly.

## Key patterns in the contract

- **Domain separation**: `pad(32, "anonimus:<domain>:")` prefixes in all `persistentHash` calls
- **Nullifiers**: `persistentHash` (NOT `transientHash`) — stable, documented for nullifiers
- **Commitments**: `persistentCommit` with random salt — defeats leaf-guessing
- **Registry**: `HistoricMerkleTree<16, Bytes<32>>` (depth 16 = 65,536 leaves)
- **`disclose()`**: required on witness-derived values entering ledger ops/exports
- **`pure circuit`**: `deriveCredId` is `export pure` — callable off-chain via `pureCircuits`
